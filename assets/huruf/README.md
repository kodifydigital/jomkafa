# Sebutan huruf (assets/huruf)
Satu fail bagi setiap huruf, dinamakan ikut kod Unicode huruf itu (contoh: ب U+0628 → u0628.mp3).
- Huruf hijaiyah: suara Arab lelaki (Microsoft Neural ar-SA-HamedNeural), nama huruf berbaris, contohnya بَا, جِيمْ, عَيْنْ.
- Huruf Jawi tambahan (چ ڠ ڤ ڬ ۏ ڽ ى): suara Melayu (ms-MY-OsmanNeural).

Untuk guna rakaman imam/ustaz sendiri: rakam setiap huruf, simpan sebagai MP3 dengan nama fail yang sama, dan gantikan fail di sini. Kod permainan tidak perlu diubah.
